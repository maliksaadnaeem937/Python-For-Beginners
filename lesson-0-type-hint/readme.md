Type Hinting in python
Type hinting is a method used in python to tell which data types does a variable have.
It does not enforce that datatype. Meaning it is just used for developers to keep track what kind of data variable will contain
and If we want to store any other datatype in that variable we can store.
Example
age:int="ten"
print(age)
It will not throw any error because "int" is only used for developers not to enforce int datatype to variable "age".
